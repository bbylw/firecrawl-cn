## 合规与责任

<Aside type="caution" title="最终用户责任">
**最终用户有责任在抓取时遵守网站政策。** 建议用户遵守目标站点的隐私政策和使用条款。默认情况下，Firecrawl 会遵守 robots.txt 指令；使用 Firecrawl 即表示你同意遵守这些条件。
</Aside>

实践上的几点提醒：

- 抓取前确认你对目标数据的使用是被允许的，尤其是需要登录才能访问的内容
- 尊重 robots.txt：默认行为由它约束，若要偏离，请先确认目标站点的政策与你的法律义务
- 控制频率：把 `limit` 等参数设在你真正需要的范围，避免给目标站点造成不必要的压力
- 谨慎存储个人数据：抓到的页面可能包含个人信息，落库前明确保留期限与处理依据
- 注明来源：把响应里的 `metadata`（标题、来源 URL）随内容一起保存，便于引用与审计
