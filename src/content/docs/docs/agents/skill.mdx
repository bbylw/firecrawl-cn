Skill 把 Firecrawl CLI 和使用说明一起装进你的智能体环境，让它无需你写胶水代码就能获取实时网页数据。安装只需要一条命令。

## 安装

```bash
npx -y firecrawl-cli@latest init --all --browser
```

`--all` 会把技能文件安装到所有被识别到的智能体客户端，`--browser` 启用与浏览器交互相关的能力。

## 重启你的智能体

安装完成后**重启智能体**，让它重新加载技能定义，之后你就可以直接用自然语言要求它抓取、搜索或爬取网页。

<Aside type="caution" title="别跳过重启">
技能清单在会话启动时读取。如果安装后智能体仍然说它无法访问网络，多半是还没重启。
</Aside>

## 支持的客户端

- [Claude Code](https://claude.ai/code)
- [Antigravity](https://antigravity.google)
- [OpenCode](https://opencode.ai)

以及其他能读取 CLI 技能文件的智能体环境。

## 使用方式

装好之后，CLI 本身就是智能体的工具箱，人也可以直接在终端里用同一套命令：

```bash
firecrawl scrape https://firecrawl.dev
firecrawl search "firecrawl" --limit 5
firecrawl interact exec --prompt "Search for 'mechanical keyboard'"
```
